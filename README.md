# Python Learning Repository

A comprehensive collection of Python programs designed to help beginners master fundamental programming concepts including operators, data types, variables, and basic algorithms.

## 📁 Project Structure

This repository contains the following Python files:

### Core Concepts
- **`arthmetic opreator.py`** - Explores arithmetic operators (+, -, *, /, //, %, **) and mathematical operations
- **`assignmemt operator.py`** - Demonstrates assignment operators and variable assignment patterns
- **`comparition operator.py`** - Covers comparison operators (==, !=, <, >, <=, >=) and boolean logic
- **`rules and Data Type of the variables and logical opreaters.py`** - In-depth guide on Python data types (int, float, str, bool, list, dict) and logical operators (and, or, not)

### Practical Programs
- **`frist.py`** - First Python program; basic introduction to print statements and simple output
- **`square and cube.py`** - Program that calculates and displays square and cube values
- **`module.py`** - Demonstrates Python modules and imports

## 🎯 Learning Outcomes

By working through these programs, you will learn:

✅ Arithmetic operations and mathematical expressions  
✅ Variable assignment and data types  
✅ Comparison and logical operations  
✅ Boolean values and conditional logic  
✅ Python syntax and basic program structure  
✅ Working with modules in Python  
✅ Mathematical calculations and algorithms  

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your system
- A text editor or IDE (VS Code, PyCharm, etc.)

### Running the Programs

1. **Clone or download** this repository to your local machine

2. **Open a terminal/command prompt** and navigate to the project directory:
   ```bash
   cd "path/to/OM Folder"
   ```

3. **Run any Python file** using:
   ```bash
   python filename.py
   ```
   
   Example:
   ```bash
   python "frist.py"
   python "square and cube.py"
   python "arthmetic opreator.py"
   ```

## 📚 Recommended Learning Order

1. Start with **`frist.py`** - Get comfortable with basic Python syntax
2. Move to **`arthmetic opreator.py`** - Learn mathematical operations
3. Study **`assignmemt operator.py`** - Understand variable assignment
4. Explore **`comparition operator.py`** - Learn comparisons and conditionals
5. Deep dive into **`rules and Data Type of the variables and logical opreaters.py`** - Master data types and logic
6. Practice with **`square and cube.py`** - Apply learned concepts
7. Experiment with **`module.py`** - Understand modular programming
